# Projeto de Refatoração POO — Geração Caldeira 2026

Projeto desenvolvido durante o **Geração Caldeira 2026** como atividade de reforço e prática dos conceitos de **Programação Orientada a Objetos (POO)**.

A partir de um projeto temático inspirado no universo de **Minecraft**, o código inicialmente desenvolvido foi refatorado com o objetivo de melhorar sua estrutura, organização e aplicação dos princípios de orientação a objetos.

Durante a refatoração, foram criadas novas classes e responsabilidades, além da aplicação de **Design Patterns**, buscando tornar o código mais organizado, reutilizável e de fácil manutenção.

## Objetivos

* Reforçar conceitos fundamentais de Programação Orientada a Objetos;
* Praticar refatoração de código existente;
* Melhorar a organização e separação de responsabilidades;
* Criar novas classes seguindo os princípios de POO;
* Aplicar Design Patterns na resolução de problemas do projeto;
* Desenvolver um código mais organizado, reutilizável e manutenível.

## Conceitos aplicados

O projeto aborda conceitos como:

* Programação Orientada a Objetos;
* Classes e objetos;
* Encapsulamento;
* Herança;
* Polimorfismo;
* Abstração;
* Separação de responsabilidades;
* Refatoração;
* Design Patterns;
* Boas práticas de desenvolvimento.

## Temática

O projeto utiliza **Minecraft** como temática para tornar a atividade mais prática e facilitar a aplicação dos conceitos de POO.

A estrutura do projeto foi utilizada como base para experimentar diferentes formas de modelar entidades, comportamentos e responsabilidades através de classes e objetos.

## Refatoração

O principal objetivo da atividade foi partir de uma implementação inicial e evoluí-la por meio da refatoração.

Durante esse processo, o código foi reorganizado para:

* Reduzir responsabilidades concentradas em uma única classe;
* Criar classes específicas para diferentes elementos do sistema;
* Melhorar a reutilização do código;
* Facilitar a manutenção e expansão do projeto;
* Aplicar princípios de orientação a objetos de forma mais adequada.

## Design Patterns

Como parte da evolução do projeto, foram utilizados **Design Patterns** para estruturar determinadas soluções e reduzir o acoplamento entre as partes do sistema.

A aplicação dos padrões teve como objetivo não apenas utilizar uma solução pronta, mas compreender **quando e por que determinados padrões podem ser utilizados durante o desenvolvimento de software**.

## Aprendizados

Este projeto permitiu reforçar conhecimentos de **Programação Orientada a Objetos** e compreender melhor a importância de uma boa modelagem de classes e responsabilidades.

A atividade também proporcionou contato prático com **refatoração e Design Patterns**, demonstrando como uma implementação inicialmente simples pode ser evoluída para uma estrutura mais organizada e preparada para futuras funcionalidades.
